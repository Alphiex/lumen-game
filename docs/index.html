LUMEN

An atmospheric, one-thumb mobile exploration game. Guide a small spirit-fox through fog-shrouded biomes, lighting lanterns and chasing memories that dissolve at the edge of sight.

WebGL build coming soon — the page below is the Three.js art reference scene that the Unity build is calibrated against.
Art Reference Scene

Interactive Three.js scene used as the lighting and atmosphere benchmark for the Unity URP build. Click and drag to orbit; scroll to zoom. The Unity build matches this lighting key, fog density, bloom curve, and color tone — rendered in real time on mobile and WebGL.

Game

  • One-thumb touch — hold to summon, tap to ping
  • Spirit-fox tracks a wisp of light you control
  • Memory motes refill the daylight timer
  • No fail state — only quieter and louder moments

Tech

  • Unity 2022.3 LTS + Universal Render Pipeline
  • iOS · Android · WebGL
  • NavMesh AI · Procedural mesh prototype
  • Quaternius low-poly nature pack

Status

  • Scene wired with fox, motes, gate, UI
  • NavMesh baked, fox follows wisp
  • URP volume tuned (bloom, vignette, tonemap)
  • WebGL build module pending install
